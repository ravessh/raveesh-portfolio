# Raveesh B M - Student Portfolio

A beginner-friendly portfolio website created for an IPS assignment using HTML, CSS and JavaScript with AI assistance.

## Files
- index.html - website structure
- style.css - design and responsive layout
- script.js - small JavaScript interaction

## Run locally
Open `index.html` in a browser.

## Before submission
1. Replace the placeholder email in `index.html`.
2. Add or remove projects based on your actual work.
3. Upload these files to GitHub.
4. Deploy the GitHub repository using Vercel or Netlify.
